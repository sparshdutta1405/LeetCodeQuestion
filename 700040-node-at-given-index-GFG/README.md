# [Node at Given Index](https://www.geeksforgeeks.org/problems/node-at-a-given-index-in-linked-list/1)
## Easy
Given the head of a singly linked list and an integer k, find the value of the node present at the given 1-based index x. Return -1 if no node exists at the given index.
Examples :
Input: k = 3, Output: 3
Explanation: The node value at index 3 is 3.

Input: k = 6, Output: -1Explanation: The linked list contains fewer than 6 nodes, so no node exists at index 6.
Constraints:1 ≤ number of nodes ≤ 1051 ≤ node-&gt;data ≤ 1051 ≤ k ≤ 105
