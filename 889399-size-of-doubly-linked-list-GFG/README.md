# [Size of Doubly Linked List](https://www.geeksforgeeks.org/problems/size-of-doubly-linked-list--114556/1)
## Easy
Given a doubly linked list. The task is to find the number of nodes in the doubly linked list.
Examples:
Input:&nbsp; 1&lt;-&gt;2&lt;-&gt;3&lt;-&gt;4Output: 4Explanation: The size of the liked list is 4 which is the number of nodes in it
Input:&nbsp; 1&lt;-&gt;2output: 2Explanation: The size of the liked list is 2 which is the number of nodes in it. 
Constraints:
1 ≤ number of nodes ≤ 1091 ≤ node-&gt;data ≤ 109
