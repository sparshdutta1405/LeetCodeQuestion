# [Linked List Traversal](https://www.geeksforgeeks.org/problems/linkedlist-traversal/1)
## Easy
Given a linked list that contains integer elements. Iterate through the given list and print its elements separated by a space.Examples:Input:Output: 1 2 3 4
Explanation: Iterating through the linked list prints 1, 2, 3, and 4.Input:Output: 2 7 10 9 8 
Explanation: Iterating through the linked list prints 2, 7, 10, 9 and 8.
