# [Is Linked List Length Even](https://www.geeksforgeeks.org/problems/linked-list-length-even-or-odd/1)
## Easy
Given a linked list, check whether the length of the linked list is even or not. Return true if it is even, otherwise false.
Examples:
Input: Linked list: 12-&gt;52-&gt;10-&gt;47-&gt;95-&gt;0Output: trueExplanation: The length of the linked list is 6 which is even.
Input: Linked list: 9-&gt;4-&gt;3Output: falseExplanation: The length of the linked list is 3 which is odd.
Constraints:1 ≤ number of nodes ≤ 1051 ≤ elements of the linked list ≤ 105
