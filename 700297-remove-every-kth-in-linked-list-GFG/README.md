# [Remove Every k'th in Linked List](https://www.geeksforgeeks.org/problems/remove-every-kth-node/1)
## Easy
Given a singly linked list head ,&nbsp; your task is to remove every kth node from the linked list.
Note: If&nbsp;head is equal to null the driver code will print -1.
Examples:
Input: k = 2Output: Explanation: After removing every 2nd node of the linked list, the resultant linked list will be: 1 -&gt; 3 -&gt; 5.
Input: k = 3Output: Explanation: After removing every 3rd node of the linked list, the resultant linked list will be: 1 -&gt; 2 -&gt; 4 -&gt; 5 -&gt; 7 -&gt; 8 -&gt; 10.
