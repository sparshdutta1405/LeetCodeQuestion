# [Reverse Array Using Stack](https://www.geeksforgeeks.org/problems/reverse-array-using-stack--143151/1)
## Easy
Given an array arr[], reverse the array elements in-place by using a&nbsp;stack.
Examples :
Input: arr[] = [1, 2, 3, 4, 5]
Output: 5 4 3 2 1
Explanation: After the reverse, array will look like [5, 4, 3, 2, 1].
Input: arr[] = [1]
Output: 1
Explanation: After the reverse, array will look like [1].
Constraints:1 ≤ arr.size() ≤ 105
