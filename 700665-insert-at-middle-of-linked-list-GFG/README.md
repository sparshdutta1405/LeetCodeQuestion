# [Insert at Middle of Linked List](https://www.geeksforgeeks.org/problems/insert-in-middle-of-linked-list/1)
## Easy
Given the head of a Singly Linked List and a value x. Insert the key in the middle of the linked list.
Examples :
Input: 1-&gt;2-&gt;4, x = 3
Output: 1-&gt;2-&gt;3-&gt;4
Explanation: 
Input: 10-&gt;20-&gt;40-&gt;50, x = 30
Output: 10-&gt;20-&gt;30-&gt;40-&gt;50
Explanation: 
Constraints:0 ≤ number of nodes ≤ 1050 ≤ node-&gt;data , x ≤ 103
