# [Check If Circular Linked List](https://www.geeksforgeeks.org/problems/circular-linked-list/1)
## Easy
Given the head&nbsp;of a singly linked list, Returns true if the linked list is circular &amp; false if it is not circular. A linked list is called circular if it is not NULL terminated and all nodes are connected in the form of a cycle.&nbsp;Note: Linked list should not contain any inner loop.
